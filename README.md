# Qinzhen Li — Academic Website

Static academic website for Qinzhen Li, published with GitHub Pages at
`https://qinzhenli.github.io/`.

## Updating the site

- Edit `index.html` for content.
- Edit `styles.css` for typography, spacing, and colors.
- Replace the PDF or image files while keeping their filenames to update those assets.
- Push changes to the `main` branch; GitHub Pages publishes the updated site automatically.
